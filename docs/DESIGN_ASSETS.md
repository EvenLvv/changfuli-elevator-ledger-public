# 界面素材

界面沿用已确认的横向导航、冷白底色、蓝色重点与轻量台账设计。首页继续使用电梯厅实景配图 `frontend/src/assets/elevator-lobby.jpg`；原有示意图 `frontend/src/assets/architecture.svg` 仅作为源码历史素材保留，不用于首页配图或应用图标。

2.0 桌面版图标采用钴蓝（`#435ddd`）、墨灰（`#28313b`）与白色“27”字标设计，随仓库提供多尺寸 `scripts/desktop-app-2.0.ico`、高清 `scripts/desktop-app-2.0.png` 及网页图标 `frontend/src/assets/desktop-app-2.0.png`；旧版 `scripts/windows-app.ico` 仅作历史兼容保留，不再用于 2.0 打包。字体使用系统本地字体，素材随前端构建，运行不请求外部图片服务。

早期本地版本曾使用第三方建筑摄影作视觉参考，该照片未纳入公开仓库。部署单位可用自行拍摄并有权使用的照片替换首页配图后重新构建。
